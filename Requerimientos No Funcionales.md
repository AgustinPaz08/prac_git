
Requerimientos no funcionales
Rendimiento
RNF-01: El sistema deberá responder a cualquier consulta o transacción en un tiempo máximo de 5 segundos.
RNF-02: El sistema deberá soportar al menos 50 usuarios conectados simultáneamente sin afectar su rendimiento.
Seguridad
RNF-03: El acceso al sistema requerirá autenticación mediante nombre de usuario y contraseña.
RNF-04: Solo los usuarios con permisos de administrador podrán crear, modificar o eliminar cuentas de usuario.
RNF-05: El sistema realizará copias de seguridad automáticas de la base de datos cada 24 horas.
Disponibilidad
RNF-06: El sistema deberá estar disponible las 24 horas del día, los 7 días de la semana, salvo durante tareas de mantenimiento programadas.
Usabilidad
RNF-07: La interfaz del sistema deberá ser intuitiva y de fácil uso para el personal administrativo.
RNF-08: El sistema mostrará mensajes de error claros cuando se ingresen datos incorrectos o incompletos.
RNF-09: El sistema contará con un manual de usuario para facilitar su utilización.
Compatibilidad
RNF-10: El sistema deberá ser compatible con los navegadores Google Chrome, Microsoft Edge y Mozilla Firefox.
RNF-11: El sistema deberá funcionar correctamente en computadoras con Windows 10 o superior.
Mantenibilidad
RNF-12: El código del sistema deberá estar documentado para facilitar futuras actualizaciones y mantenimiento.
