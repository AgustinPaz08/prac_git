Eficiencia (Rendimiento y Concurrencia): El sistema debe ser capaz de soportar hasta 200 usuarios concurrentes interactuando simultáneamente sin degradar el servicio. El tiempo de respuesta del servidor para cualquier consulta de estado de cuenta de socios no debe exceder los 2 segundos bajo condiciones normales de red.

Seguridad lógica y de datos: Todas las contraseñas de los usuarios almacenadas en la base de datos deben estar encriptadas utilizando el algoritmo de hash robusto SHA-256 o bcrypt. Se deben realizar respaldos (backups) automáticos y completos de la base de datos de "El buen descanso" cada 24 horas a las 02:00 AM, almacenándose de forma segura en un servidor secundario aislado.

Usabilidad: Un usuario administrativo estándar debe ser capaz de aprender a registrar un servicio fúnebre completo en el software en un tiempo máximo de aprendizaje de 1 hora de capacitación interna. Además, ante cualquier error en la carga de datos de afiliación, el sistema debe mostrar un mensaje claro y amigable orientando al usuario sobre cómo corregirlo (ej: "El formato del correo es inválido, asegúrese de incluir un @"), en lugar de arrojar códigos de error del servidor.
