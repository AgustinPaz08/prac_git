Requerimientos funcionales
Administración de socios:
Descripción: Permite administrar la información de los socios de la empresa.
Prioridad: Alta
Requerimientos funcionales asociados: 
RF-01: El sistema permitirá registrar un nuevo socio.
RF-02: El sistema permitirá modificar los datos de un socio.
RF-03: El sistema permitirá eliminar un socio.
RF-04: El sistema permitirá buscar un socio por nombre o cédula.


RF-01: El sistema permitirá registrar un nuevo socio. 
Descripción: Permite registrar un nuevo socio ingresando sus datos personales y de contacto para incorporarlo al sistema.
Prioridad: Alta.
Acciones iniciadoras: El usuario selecciona la opción “Registrar socio”, completa el formulario con los datos requeridos (nombre, cédula, dirección, teléfono, correo electrónico, etc).
Requerimientos funcionales asociados: 
RF-02: Modificar datos de un socio
Descripción: Permite actualizar la información de un socio ya registrado.
Prioridad: Alta.
Acciones iniciadoras: El usuario busca al socio, selecciona "Editar", modifica los datos y guarda los cambios. El sistema actualiza la información.
RF-03: Eliminar un socio
Descripción: Permite dar de baja a un socio del sistema.
Prioridad: Alta.
Acciones iniciadoras: El usuario selecciona un socio, elige la opción "Eliminar" y confirma la acción. El sistema elimina el registro.
RF-04: Buscar un socio
Descripción: Permite localizar un socio por nombre o cédula.
Prioridad: Alta.
Acciones iniciadoras: El usuario ingresa un criterio de búsqueda y el sistema muestra los resultados encontrados.
