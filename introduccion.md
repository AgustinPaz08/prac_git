 
El sistema denominado “El Buen Descanso” versión 1.0 es una aplicación web diseñada para la gestión de afiliaciones, control de socios y administración de pagos de la empresa funeraria El Buen Descanso. 
Este documento cubre la totalidad del sistema, 
En cuanto al alcance del producto, esta ESRE cubre la totalidad del sistema “El Buen Descanso”, incluyendo los módulos de solicitud de afiliación web, gestión de socios, administración del núcleo familiar y control de pagos. No se incluyen en este documento sistemas externos como plataformas contables o servicios de terceros, ni módulos adicionales que no formen parte del alcance definido del proyecto.
